🌐 Swarnamali Portfolio

A modern, responsive, and dynamic personal portfolio website designed and developed by **Swarnamali Dassanayake**.

Unlike template-based portfolios, this website is built entirely around my own design concepts, layout structure, and development style. Every section, component, and interaction has been custom designed to reflect my personal identity and showcase my technical skills and projects.

---

## ✨ Features

* 🎨 Completely custom UI/UX design
* 📱 Fully responsive for desktop, tablet, and mobile devices
* 🌙 Modern gradient-based interface
* ⚡ Dynamic content loaded from Firebase Realtime Database
* 🖼 Dynamic project galleries with image/video support
* 💼 Work experience section
* 🎓 Education section
* 🛠 Technical skills with animated progress bars
* 📂 Categorized project showcase
* 📞 Contact & social media integration
* 📄 Resume download
* ☁ Cloudinary integration for media storage

## 🚀 Dynamic Content

The portfolio retrieves content directly from Firebase, including:

* General Settings
* Skills
* Projects
* Work Experience
* Education
* Social Links

This allows the website to be updated without modifying the source code.

---

## 🎯 Design Philosophy

This portfolio was **not built using a ready-made template**.

Every page, section, layout, animation, and component has been designed and developed according to my own ideas and coding style. The objective was to create a portfolio that represents both my personality and my approach to software development.

---

## 📸 Media

Images and videos are stored using Cloudinary, while structured content is managed through Firebase Realtime Database.

## 💻 Local Setup

Clone the repository:

```bash
git clone https://github.com/<your-username>/swarnamali-portfolio.git
```

Open the project folder:

```bash
cd swarnamali-portfolio
```

Run with any local server.

Examples:

* Live Server (VS Code)
* XAMPP
* Firebase Hosting
